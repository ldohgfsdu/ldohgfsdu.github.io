① 导入 Anki 卡包

优先选择左边约 10.57 MB 的绪论卡包。安卓文件选择器中的灰色文档图标不代表文件不可用；点文件卡片后应返回本页并开始读取。若无响应，可用 Chrome 浏览器打开此网页。360 MB 卡包暂不在本版支持范围内。

目前兼容范围和限制
可读取传统 collection.anki2、collection.anki21 和新版 zstd collection.anki21b；新版卡片模板可从 Protobuf 读取。读取旧版 JSON 或新版 Protobuf 媒体索引。支持基础正反面、文本 Cloze、以 Question Mask / Answer Mask 保存的图片遮挡卡，以及 Kevin Image Cloze（PDF Guru） 这类把遮挡矩形存进 Masks 字段的图片挖空卡：正面按归一化坐标还原遮挡层，可点击任意红条逐个原位揭晓，也可点击「显示答案」揭晓所有剩余遮挡；不生成第二张图片，并已移除模板自带导航箭头。Anki 原生 Image Occlusion 的复杂 SVG 遮挡仍不能保证保真，检测到时会给出提示。FSRS 使用固定版本 ts-fsrs；如果加载失败，复习评分不会伪称已保存。当前属于独立实验页，不是原 Netlify 网站的正式上线版本。
